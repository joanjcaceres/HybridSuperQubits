API reference
=============

This section documents the public API of HybridSuperQubits. All qubit classes
inherit from :py:class:`~HybridSuperQubits.qubit_base.QubitBase`, which provides
common methods for diagonalization, parameter sweeps, noise analysis, and
visualization.
