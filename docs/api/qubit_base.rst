QubitBase
=========

Abstract base class for all superconducting qubits. Provides shared methods for
Hamiltonian diagonalization, parameter sweeps, matrix element computation, noise
analysis, and wavefunction utilities.

All qubit types in HybridSuperQubits inherit from this class.
