Ferbo
=====

The Fermionic-Bosonic (FerBo) qubit: a hybrid semiconductor-superconductor circuit
coupling Andreev bound states in a weak link to the bosonic mode of an LC oscillator.

See :doc:`/theory` for the physics background and the
`companion paper <https://arxiv.org/abs/2604.01145>`_ for a detailed treatment.
